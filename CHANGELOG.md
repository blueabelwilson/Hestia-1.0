# Changelog

## 1.0.0

First release.

* App launcher with fuzzy search, Microsoft Store apps and most-used-first ranking
* Window switcher, Run box and power menu (lock, sleep, hibernate, sign out, restart, shut down)
* Setup wizard and a settings window with a live preview
* Looks built around your own picture: drag to frame it, colours taken from it
  (dark, colourful or light, with picture, Windows or custom accent colours)
* Rectangle layouts recreated from adi1090x's rofi themes, plus arch, circle and
  polygon windows with rings, box or inside menu styles
* Button shapes, any installed font, custom .svg / .ico icons, blur / acrylic / mica
* Global hotkeys and in-popup keys, all changeable
* Tray icon, start with Windows, installer and uninstaller
